# Site estático para GitHub Pages

O site usa somente HTML e CSS. Não possui PHP executável, JavaScript, animações nem links externos.

## Estrutura

- `index.html`: página principal
- `assets/css/style.css`: estilos da página
- `assets/images/`: fotos e logotipos

## Publicar no GitHub Pages

Envie o conteúdo desta pasta para um repositório no GitHub. Depois, em **Settings > Pages**, selecione **Deploy from a branch**, a branch `main` e a pasta `/(root)`.
